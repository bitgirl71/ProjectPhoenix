## English

A personal project created to rediscover the joy of programming in Python,
learn modern development tools such as Git and GitHub, and build software one step at a time.

### Naming

Every identifier must earn its right to exist.

Names are chosen for clarity, not originality... but they are not ornaments.

Sometimes a Latin or Greek term can express an idea more precisely than a modern word.
When this happens, the etymology becomes part of the documentation, never decoration.

So, a Latin or Greek word is welcome only when it expresses the concept more clearly than any modern alternative.

Examples:
- limen — the boundary that must not be crossed.
- index — the pointer to a position.

They exist to reveal intention.


### Project philosophy *(work in progress)*

> First build. Then refine.
> There is always time to simplify.
> Every line must earn its right to exist.
> For humans, abstraction emerges through reflecting on the concrete.
