# Project Phoenix

## Italiano

Un progetto personale nato per riscoprire il piacere di programmare in Python,
imparare strumenti moderni come Git e GitHub e costruire software un passo alla volta.

### Filosofia del progetto *(in fieri)*

> Prima si costruisce. Poi si rifinisce.
> Si fa sempre in tempo a sfoltire.
> Ogni riga deve guadagnarsi il diritto di esistere.

---

## English

A personal project created to rediscover the joy of programming in Python,
learn modern development tools such as Git and GitHub, and build software one step at a time.

### Project philosophy *(work in progress)*

> First build. Then refine.
> There is always time to simplify.
> Every line must earn its right to exist.

---

Created with curiosity, patience, and countless conversations.
